# docs/agents

Working files for the AI agents that build this project; tracked so every git worktree and CI checkout has them.

- `filemap.md`: navigation index of the repository (update when adding or moving files).
- `PLAN.md`: task list and status.
- `REVIEW.md`: open review findings.

Product, engineering and operations docs (SPEC, DESIGN, DEPLOY, E2E, PROCESS, MOBILE-RELEASE, `design/`) stay in `docs/`.
