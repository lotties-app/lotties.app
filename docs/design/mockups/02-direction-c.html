  • Type: rounded sans, 700-800 weights (ui-rounded / SF Pro Rounded here; ship Nunito, SIL OFL 1.1, as the cross-platform face).
  • Icons: duotone (Phosphor Icons, MIT, "duotone" weight): 2px stroke plus a 28% fill, ink on solid colour blocks.
  • Shape: 28px hero, 20-22px blocks with a 3-5px "toy block" bottom shadow; pressed = translateY(2px), shadow shrinks.
  • Signature: Pip, an original pebble-and-sprout companion that reacts to the state (asleep, awake, hungry), plus solid category blocks.
  • Coral is a fill only (ink label); on light it fails as text, so text/rings/focus use the darker coral ink.
  • Night feed: blocks collapse to outlines in one warm tone; Pip becomes a dim line drawing; no shadows, no fills.
