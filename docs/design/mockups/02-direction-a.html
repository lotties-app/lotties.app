  • Type: system UI stack (SF / Segoe UI / Roboto), 650 for titles, tabular numerals everywhere.
  • Icons: Material Symbols Rounded geometry (outlined, 1.9px at 24px); the selected nav item switches to the filled variant.
  • Shape: 28px hero and sheet, 20px cards and tiles, 999px chips; floating 26px nav bar.
  • Signature: dusk gradient (lavender to apricot) only on the prediction ring and the baby avatar ring.
  • Primary action is always the warm "horizon" colour (FAB, Save, running pill); selections use lavender/indigo.
  • Night feed: one warm tone, no blue channel above 0x72, text at ~45% of normal luminance.
