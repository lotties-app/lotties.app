# App icon art

Concept B, "Day disc", is the app icon (decision and rationale: `../07-app-icon.md`). The other concepts (`*-a*`, `*-c*`, `*-d*`, `*-e*`) are kept as design history only; nothing ships them. All files are hand-built SVG, original work by the project contributors, AGPL-3.0-or-later. There is no generator: edit the SVGs.

## Files of concept B and where they are used

| File | Used for |
| --- | --- |
| `icon-b.svg` | Light tile, 1024 grid. Copied to `web/public/icon.svg`; PNGs `icon-192.png`, `icon-512.png`; the README logo. |
| `icon-b-dark.svg` | Dark tile (warm dark, ivory crescent). Rendered as `icon-dark-192.png`, `icon-dark-512.png`; reference for the dark colours in `web/src/ui/BrandMark.tsx`. |
| `icon-b-maskable.svg` | Full bleed, glyph scaled to 0.78 (inside the 66% safe zone). Rendered as `icon-maskable-512.png`; at 0.92 as the opaque `apple-touch-icon.png`. |
| `icon-b-maskable-dark.svg` | Dark counterpart of the maskable art: full-bleed dark tile, glyph at 0.78. Rendered as `icon-maskable-dark-512.png`; at 0.92 as the opaque `apple-touch-icon-dark.png` (180, no alpha). |
| `icon-b-mono.svg` | Silhouette (alpha only), thick shapes for 24 px. Rendered at 0.6 inside 512 px as `icon-monochrome-512.png` (manifest `purpose: monochrome`); shared by the light and dark manifests, only its alpha is used. |
| `favicon-b.svg` | Simplified 32 grid drawing (larger disc, whole-pixel ruler, flat colour, dark palette via `prefers-color-scheme`). Copied to `web/public/favicon.svg` and `keycloak-theme/src/login/art/favicon.svg`; rendered as `favicon.png` (32) and `favicon.ico` (16, 32, 48); with the dark palette forced by the generator as `favicon-dark.png` and `favicon-dark.ico`. |
| `lockup-b.svg` | Icon plus live Fraunces text (outline the text for final art). Reference only. |

The drawing in `web/src/ui/BrandMark.tsx` (app) and `keycloak-theme/src/login/art/BrandMark.tsx` (sign-in theme) repeats the shapes of `icon-b.svg` (above 32 px) and `favicon-b.svg` (32 px and under). Keep them in step when the art changes.

## Regenerate

```bash
cd web
node scripts/generate-icons.mjs            # light and dark PNGs, favicon(-dark).ico, copies of the SVGs (needs the sharp devDependency)
node scripts/generate-social-preview.mjs   # ../docs/design/social-preview.png (needs e2e/node_modules with Chromium)
```

`docs/design/social-preview.png` (1200x630) is the repository social preview; upload it in GitHub under Settings > General > Social preview.

## Light and dark sets at run time

Every surface that shows the icon has a light and a dark variant; the dark one shows on dark wallpapers, dark browser tabs and while the app is dark or night.

| Surface | How it picks |
| --- | --- |
| Tab icon | `web/index.html`: `favicon.svg` (scheme-aware itself) plus PNG links with `media="(prefers-color-scheme: light or dark)"` (`favicon.png` / `favicon-dark.png`). Follows the browser/OS theme, not the in-app theme choice. |
| Web manifest | There is no dark icon field, so `web/pwa-manifest.ts` defines two manifests with the same `id`, `name`, `start_url`, `scope`: `manifest.webmanifest` (light icons, light colours; generated by VitePWA) and `manifest-dark.webmanifest` (dark icons, dark colours; emitted by `darkManifestPlugin`). `public/theme-init.js` (before first paint) and `AppThemeProvider` (when the user switches) point `<link rel="manifest">` at one of them (`src/pwa/schemeLinks.ts`; night counts as dark). Both are precached and served `no-cache`. |
| iOS home screen | `<link rel="apple-touch-icon">` has no media support: the same scripts set its href to `apple-touch-icon.png` or `apple-touch-icon-dark.png`. |

An installed PWA keeps the icon the manifest had at install time; the OS decides when to refresh it. Check the result against the built app with `cd e2e && npx playwright test -c design-review/icons-dark.config.ts` (port 5180; screenshots `docs/design/screenshots/icons-dark-*.png`).

Colours: `07-app-icon.md` section "Colours". The light manifest uses the light scheme tokens (`theme_color`/`background_color` `#f5efe4`), the dark one the dark scheme tokens (`#1b1814`), both from `web/src/theme/tokens.ts`.
